Global test scenarios

A global test scenario belongs to no requirement and is checked against all of them, e.g. key is in the ignition and turned → the engine runs. It is exported to the .req file as NAME: TestScenario for ALL, trace .... The test scenarios of a single requirement are edited in the requirement.

Import file

One test scenario per line, as in the .req export: NAME: TestScenario for <RID | ALL>, trace has to hold: (duration, formula), ... Other lines are ignored, so a whole .req file can be imported. Scenarios of a requirement are shown in that requirement.
